Listopic · Sistema de paletas

Cuatro temas, mismos tokens

Cada paleta usa el mismo conjunto de variables CSS (--lt-*). Cambias de tema poniendo class="theme-dark" (o light/warm/cool) en <html> o <body>.

Cómo aplicarlo

1. Copia el bloque :root + .theme-* de cada paleta a tu CSS global.

2. En tus componentes, usa las variables en vez de hexadecimales:

background: var(--lt-bg);
color: var(--lt-text);
border: 1px solid var(--lt-border);

.card { background: var(--lt-card); }
.accent-btn { background: var(--lt-accent-grad); }

3. Para cambiar de tema, añade una clase al elemento raíz:

document.documentElement.className = 'theme-warm';
// o persistir en localStorage:
localStorage.setItem('listopic-theme', 'warm');

Los tokens son intercambiables entre temas — si un componente ya usa var(--lt-accent), cambia de color automáticamente al cambiar de tema. No hay if/else en componentes.
